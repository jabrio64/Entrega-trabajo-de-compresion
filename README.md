## Utilizacion 

- Abrir terminal en la carpeta donde se encuentra el archivo main
- Correr el comando:
  ```
  make
  ```
- Para ejecutar el modo de prueba, usar el comando:
  ```
  ./main --benchmark
  ```
    - Este modo de ejecucion generara un archivo CSV que contendra las estadisticas de ejecucion del programa (En desarrollo aun)

  
- Para ejecutar el modo de busqueda, usar el comando:  (En desarrollo aun)
  ```
  ./main -i <direccion del archivo csv>
